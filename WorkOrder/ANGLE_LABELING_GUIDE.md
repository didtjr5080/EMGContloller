# 저장 기록 확인과 각도 정답 입력

1. 메인 화면의 **저장 기록 보기 / 정답 입력**을 누릅니다.
2. 측정을 선택하고 **영상·근전도·각도 보기**를 누릅니다. 시간 슬라이더로 해당 시점의 영상, EMG, 자동 각도와 허리·둔부 상태를 확인할 수 있습니다.
3. **정답 데이터 입력 / 수정**에서 입력자 ID와 각도 유지 구간을 추가합니다. 시간은 기록 시작 기준 초이며, 팔꿈치를 편 자세는 180°입니다.
4. 예: 3~5초에 실제 90°를 유지했다면 시작 3, 종료 5, 정답 각도 90을 입력합니다. 허리와 둔부는 각각 고정 / 움직임 / 판단 불가 중 선택합니다. 움직여 목표 각도에 도달하는 전환 구간은 고정 각도 정답으로 넣지 않습니다.
5. **정답 저장**으로 수정 이력을 저장합니다. **EMG + 정답 학습 CSV 내보내기**는 표시한 구간의 EMG만 추출합니다. 종료 시각의 샘플은 제외됩니다.

수동 정답은 `ground_truth.jsonl`에 저장하며 원본 EMG, 영상, 자동 자세 추정, 기존 전문가 판정 파일을 바꾸지 않습니다. 자동 각도값을 수동 정답으로 복사하지 않습니다. 수동 정답과 자동 추정은 별개의 자료입니다.

학습 CSV에는 원본 샘플 필드와 `truth_elbow_angle_deg`, `truth_trunk_fixed`, `truth_pelvis_fixed`, 수정 번호가 있습니다. 판단 불가 값은 빈 칸입니다. `truth_synthetic`으로 모의 입력 여부를 구분합니다. 수신 시각으로 결합한 데이터는 `host_receive_unverified_sync`로 표시되며 물리적 장치 동기가 검증되었다는 뜻은 아닙니다.

허리·둔부 자동 판단은 양쪽 어깨와 골반이 보일 때 첫 유효 자세를 기준으로 계산합니다. 허리는 몸통 기울기 변화, 둔부는 골반 중심 이동과 기울기 변화를 사용합니다. 기본 기준은 5°와 몸통 길이의 5%이며 검증 전 설정입니다. 카메라는 고정해야 하고, 가려진 부위는 판단 불가로 표시됩니다. 기존 기록에 해당 필드가 없다면 자동 상태는 판단 불가로 표시되며 수동 정답 입력은 가능합니다.

모델은 실행 파일 내장 위치, 실행 파일 주변 `models` 폴더, 소스 프로젝트의 `models` 폴더 등을 자동 탐색합니다. 장치·진단 설정에서 **모델 자동 찾기** 또는 **모델 파일 선택**도 사용할 수 있습니다.
